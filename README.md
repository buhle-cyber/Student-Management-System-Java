#  Student Management System (Java)

A desktop application built using **Java Swing** and **NetBeans** that allows users to manage student records. The application supports CRUD operations, file persistence, undo functionality, and input validation through an easy-to-use graphical user interface.

##  Features

-  Add Student
-  Update Student
-  Delete Student
-  Search Student
-  Undo Last Delete
-  Save student records to a text file
-  Automatically load student records when the application starts
-  Input validation
  - Required fields
  - Numeric Student ID
  - Duplicate Student ID prevention
  - Email format validation
-  Custom button colours
-  Button icons

##  How to Run

1. Clone the repository

```bash
git clone https://github.com/buhle-cyber/Student-Management-System-Java.git
```

2. Open the project in NetBeans.

3. Build and run the project.

4. Start managing student records.
